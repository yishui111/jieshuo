# 项目二 · 情感解说 · 接口文档

> **项目用途**：给一段故事，按约束文档生成激情洋溢的解说词（DeepSeek，无 Key 时回退本地 Ollama），
> 再用 IndexTTS-2.5 情感引擎带情感朗读出片（兴奋/惊喜/愤怒…逐段标注，或整段统一预设）。
> 网页工作台与 REST 接口同端口（`启动.bat`，9620，FastAPI，自带 `/docs`）。

- 启动：双击本项目 `启动.bat`
- 地址：`http://127.0.0.1:9620`（交互文档 `/docs`）
- 引擎按需启停：首次点朗读会自动拉起 IndexTTS-2.5 并加载模型（本机 USB 盘实测 ~15 分钟冷加载；
  之后常驻显存，秒级出片）

## 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 工作台总状态（引擎、配置、产物列表） |
| **解说词** | | |
| GET | `/api/constraints` | 取当前约束文档（发给 LLM 的格式规范） |
| POST | `/api/constraints` | 修改约束文档 |
| POST | `/api/gen_script` | 故事 → 激情解说词 JSON（带逐段情感标注） |
| **语音合成** | | |
| POST | `/api/synth` | 解说词 → 异步合成任务（带情感） |
| GET | `/api/job/{job_id}` | 任务进度；done 带 wav 文件名 |
| GET | `/audio/{name}` | 下载/播放合成音频 |
| **引擎管理** | | |
| POST | `/api/engine/index_tts/start` | 启动引擎（端口 9602） |
| POST | `/api/engine/index_tts/stop` | 停止引擎（释放显存） |
| GET | `/api/engine/index_tts/log` | 引擎实时日志 |

## 主链路调用示例

```bash
# 1) 生成解说词（需 DeepSeek Key 填在 config.yaml，或本地 Ollama）
curl -X POST http://127.0.0.1:9620/api/gen_script -H "Content-Type: application/json" \
  -d '{"story":"决赛最后时刻，机器人完成惊天逆转……","duration":60}'
# → 解说词 JSON：{"title":..., "segments":[{"text":..., "emotion":"兴奋", "intensity":0.9}, ...]}

# 2) 提交合成（激情洋溢；emotion_mode=auto 跟随逐段标注，fixed 整段统一用 preset）
curl -X POST http://127.0.0.1:9620/api/synth -H "Content-Type: application/json" \
  -d '{"preset":"激情洋溢","emotion_mode":"auto","intensity":0.95,"speed":1.0,
       "script":{"title":"机器人逆转夺冠","segments":[
         {"text":"还在等什么？最后一局，全场都站起来了！","emotion":"兴奋","intensity":0.9},
         {"text":"他们做到了！三比二逆转，捧起冠军奖杯！","emotion":"惊喜","intensity":1.0}]}}'
# → {"job_id": "051321_1"}

# 3) 轮询；done 后下载
curl http://127.0.0.1:9620/api/job/051321_1
curl -o 解说.wav http://127.0.0.1:9620/audio/<done 返回的 wav 文件名>
```

## 说明

- 情绪预设（8 维情感向量）在 `config.yaml` 的 `tts.index_tts.presets` 里配置。
- 生成音频统一存本项目 `解说音频\`；逐段合成中间文件在 `logs\segments\`。

## 实测记录

- 2026-09-28（拆分前统一工作台）：激情洋溢合成（2 段）出片 8.5 秒 wav，引擎冷加载 ~15 分钟
  （USB 慢盘；BigVGAN 自定义内核缺 ninja 时自动回退 torch，属设计内）。
- 拆分后独立服务复测见 `测试\测试报告.md`。
