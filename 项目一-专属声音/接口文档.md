# 项目一 · 专属声音 · 接口文档

> **项目用途**：给一段故事，按约束文档生成激情洋溢的解说词（DeepSeek，无 Key 时回退本地 Ollama），
> 再用 GPT-SoVITS 用你的专属声音朗读出片（未训练时用默认参考音色零样本克隆）。
> 网页工作台与 REST 接口同端口（`启动.bat`，9610，FastAPI，自带 `/docs`）。

- 启动：双击本项目 `启动.bat`
- 地址：`http://127.0.0.1:9610`（交互文档 `/docs`）
- 引擎按需启停：首次点朗读会自动拉起 GPT-SoVITS 并加载模型（约 1~2 分钟；之后常驻显存，秒级出片）

## 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 工作台总状态（引擎、配置、当前专属声音、产物列表） |
| **解说词** | | |
| GET | `/api/constraints` | 取当前约束文档（发给 LLM 的格式规范） |
| POST | `/api/constraints` | 修改约束文档 |
| POST | `/api/gen_script` | 故事 → 激情解说词 JSON（带逐段情感标注） |
| **语音合成** | | |
| POST | `/api/synth` | 解说词 → 异步合成任务（专属声音朗读） |
| GET | `/api/job/{job_id}` | 任务进度；done 带 wav 文件名 |
| GET | `/audio/{name}` | 下载/播放合成音频 |
| **声音训练** | | |
| GET | `/api/train/materials` | 训练素材检查 |
| POST | `/api/train/start` | 一键训练（切片→标注→预处理→SoVITS/GPT 微调） |
| GET | `/api/train/status` | 训练进度与日志 |
| POST | `/api/voice/select` | 切换当前使用的声音（训练产物/历史声音） |
| **引擎管理** | | |
| POST | `/api/engine/gpt_sovits/start` | 启动引擎（端口 9885） |
| POST | `/api/engine/gpt_sovits/stop` | 停止引擎（释放显存） |
| GET | `/api/engine/gpt_sovits/log` | 引擎实时日志 |

## 主链路调用示例

```bash
# 1) 生成解说词（需 DeepSeek Key 填在 config.yaml，或本地 Ollama）
curl -X POST http://127.0.0.1:9610/api/gen_script -H "Content-Type: application/json" \
  -d '{"story":"决赛最后时刻，机器人完成惊天逆转……","duration":60}'
# → 解说词 JSON：{"title":..., "segments":[{"text":..., "emotion":"兴奋", "intensity":0.9}, ...]}

# 2) 提交合成（专属声音朗读；未训练时用默认参考音色零样本克隆）
curl -X POST http://127.0.0.1:9610/api/synth -H "Content-Type: application/json" \
  -d '{"script":{"title":"机器人逆转夺冠","segments":[
         {"text":"还在等什么？最后一局，全场都站起来了！","emotion":"兴奋","intensity":0.9},
         {"text":"他们做到了！三比二逆转，捧起冠军奖杯！","emotion":"惊喜","intensity":1.0}]},
       "speed":1.0}'
# → {"job_id": "051321_1"}

# 3) 轮询；done 后下载
curl http://127.0.0.1:9610/api/job/051321_1
curl -o 解说.wav http://127.0.0.1:9610/audio/<done 返回的 wav 文件名>
```

## 说明

- 训练一键调用 `POST /api/train/start`，产物（SoVITS/GPT 权重）落在 `GPT-SoVITS\SoVITS_weights_v2\`、
  `GPT-SoVITS\GPT_weights_v2\`，训练完自动写入 `voice_config.json` 并启用。
- 生成音频统一存本项目 `解说音频\`；逐段合成中间文件在 `logs\segments\`。
