# 激情解说 · 两个项目（专属声音训练 + 情感解说）

给一段故事（或素材），按约束文档生成激情洋溢的解说词，再用指定的声音朗读出来。
全部本地部署，一个工作台管两个项目，双击 `启动工作台.bat` 即用。

| 项目 | 声音 | 流程 |
|------|------|------|
| **项目一 · 专属声音** | 你自己的声音：把激情解说录音放进 `训练素材\`，页面一键训练出专属声音模型（GPT-SoVITS 微调） | 故事 → DeepSeek 按约束文档改写解说词 → 专属声音朗读 |
| **项目二 · 情感解说** | 开源情感声音模型 IndexTTS-2.5（B站，8 维情感向量可调情绪） | 故事 → DeepSeek 按约束文档改写解说词 → 情绪调成"激情洋溢"朗读 |

## 一、使用（只有一个入口）

双击根目录 **`启动工作台.bat`**，浏览器自动打开 `http://127.0.0.1:9610`：

1. 把你的激情解说录音放进 `训练素材\` 文件夹；
2. 工作台 → 项目一 →「刷新素材」→「开始训练」（全自动：切片 → ASR 标注 → 数据集预处理 → SoVITS 微调 → GPT 微调）；
3. 训练完成后，把故事粘进左侧 → 生成解说词 → 「用专属声音朗读」；
4. 项目二页签：故事 → 生成解说词 → 情绪选"激情洋溢" → 朗读。

语音引擎不用手动启动：点「朗读」时工作台会自动拉起对应引擎并加载模型（首次约 1~5 分钟）。

## 二、目录结构

```
启动工作台.bat               ★ 唯一入口
工作台\                       统一工作台（自研，全部入库）
├── server.py                FastAPI 服务：页面 / DeepSeek / 引擎管理 / 训练管理
├── train_voice.py           训练编排（GPT-SoVITS 全流程自动化）
├── deepseek_client.py       约束文档 + 故事 → DeepSeek 解说词（无 key 时本地 Ollama 兜底）
├── engines.py               引擎按需启停（健康检查 / 日志 / 缓存本地化）
├── 约束文档.md               约束 DeepSeek 输出格式的文档（页面里可直接改）
├── static\index.html        前端页面（双工位）
├── config.yaml              本机配置（DeepSeek key 等，不入库；模板 config.example.yaml）
├── voice_config.json        当前启用的专属声音（训练完成后自动写入）
├── outputs\ logs\ 训练数据\ model_cache\   产物、日志、训练中间数据、模型缓存（均不入库）
训练素材\                     ★ 把你的解说录音放这里（不入库）
index-tts\                    项目二引擎 IndexTTS-2.5（tts_server.py 自研入库，权重 5.2GB 本地部署）
GPT-SoVITS\                   项目一引擎 GPT-SoVITS（api_server.py 自研入库，预训练底模本地部署）
解说音频\ 演示音频\            历史生成的音频样例
```

## 三、配置（工作台\config.yaml）

| 配置 | 说明 |
|------|------|
| `deepseek.api_key` | 你的 DeepSeek API Key；留空则读环境变量 `DEEPSEEK_API_KEY`；都没有时用本地 Ollama 兜底生成解说词 |
| `tts.index_tts.presets` | 项目二的情绪预设表（激情洋溢/兴奋/愤怒…→ 8 维情感向量），可自行加减 |
| `training.*` | 训练默认轮数与批大小（16GB 显存默认值已调好） |
| `paths.materials_dir` | 训练素材目录 |

所有组件的 HF / ModelScope 模型缓存都通过环境变量固定在 `工作台\model_cache\`，**不占 C 盘**。

## 四、约束文档

`工作台\约束文档.md` 就是发给 DeepSeek 的"格式法律"：输出 JSON 结构（title + segments），
每段 20~40 字并带 `emotion`（九种情感）与 `intensity`（0~1）标注，规定开场炸场、中段起伏、
结尾收束的节奏。**在工作台页面里直接改、保存，下一条解说词就按新规则生成。**

## 五、训练细节（项目一）

- 素材：3~30 分钟、无 BGM 的清晰解说人声（mp3/wav/m4a 均可），放 `训练素材\`；
- 流程：静音切片（4~15s）→ Fun-ASR-Nano 标注 → GPT-SoVITS 三连预处理 →
  SoVITS v2 微调（12 轮）→ GPT v2 微调（15 轮），全程页面看日志；
- 产物：`GPT-SoVITS\SoVITS_weights_v2\`、`GPT-SoVITS\GPT_weights_v2\` 下以任务名命名的权重，
  训练完自动作为当前声音启用（也会自动挑一条 10~30 字的切片作推理参考音频）；
- 显存：RTX 4080 16GB 可直接训；训练和合成不要同时跑。

## 六、常见问题

- **点朗读没反应/失败**：首次合成要启动引擎并加载模型（1~5 分钟），页面状态条看引擎是否"就绪"；
  详情看工作台「引擎日志」。
- **生成解说词报 DeepSeek 未配置**：正常，自动走本地 Ollama（效果稍弱）；配置 key 后无需重启。
- **训练按钮报素材为空**：录音还没放进 `训练素材\`，或格式不在 mp3/wav/flac/m4a/ogg 里。
- **显存不足**：16GB 同一时间只跑一个引擎；训练时不要合成，合成时不要训练（工作台会按需切换）。
- **换音色/情绪**：项目一换录音重训；项目二改情绪预设表或页面上的情绪/强度滑杆。
