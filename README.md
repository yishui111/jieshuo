# 激情解说 · 工作台

给一段故事，按约束文档生成激情洋溢的解说词，再用你指定的声音朗读出来。
**启动方式只有一个：双击 `启动工作台.bat`**，浏览器自动打开 `http://127.0.0.1:9610`。

```
故事（或素材文字）
   │  DeepSeek 按「约束文档」改写
   ▼
激情解说词（每段带情感标注：兴奋 0.9 / 惊喜 1.0 …）
   │  逐段交给语音引擎带情感朗读，自动拼接
   ▼
解说音频（wav）
```

## 两个项目

| | 声音 | 说明 |
|---|------|------|
| **项目一 · 专属声音** | **你自己训练出来的声音** | 把激情解说录音放进 `训练素材\`（3~30 分钟，无 BGM），页面「开始训练」全自动完成：切片 → 语音识别标注 → 数据预处理 → SoVITS 微调 → GPT 微调（引擎 GPT-SoVITS） |
| **项目二 · 情感解说** | **IndexTTS-2.5 情感声音模型** | 情绪可调：激情洋溢 / 兴奋 / 愤怒 / 惊喜…，可跟随解说词逐段情感标注，也可整段统一（引擎 IndexTTS-2.5，B站开源） |

## 使用步骤

1. 双击 `启动工作台.bat`（首次运行先双击 `工作台\修复wetext.bat` 修复引擎依赖，见下文常见问题）；
2. 打开 `工作台\config.yaml`，在 `deepseek.api_key` 填入你的 DeepSeek Key
   （[platform.deepseek.com](https://platform.deepseek.com) 申请；不填则无法生成解说词，保存后立即生效、无需重启）；
3. 页面左侧输入故事 → 「生成激情解说词」→ 右侧点「朗读」→ 播放/下载音频；
4. 项目一：先训练（页面有素材检查和实时日志），训练完自动启用，即可用你的声音朗读。

产物保存在 `解说音频\`。

## 目录说明

```
启动工作台.bat            唯一入口（自动处理端口占用、崩溃自动重启）
工作台\                   统一后端 + 前端页面
├── server.py             后端服务：页面 / 解说词 / 合成任务 / 训练任务 / 引擎管理
├── train_voice.py        项目一的训练编排（调用 GPT-SoVITS 的训练脚本）
├── deepseek_client.py    约束文档 + 故事 → DeepSeek → 解说词 JSON
├── engines.py            语音引擎按需启停（IndexTTS-2.5 / GPT-SoVITS）
├── fix_wetext.py         引擎依赖修复脚本（修复wetext.bat 调用它）
├── 约束文档.md            发给 DeepSeek 的输出格式约束（页面里可直接改）
├── config.yaml           本机配置（DeepSeek Key、情绪预设等；模板 config.example.yaml）
└── static\index.html     前端页面
训练素材\                 ★ 项目一：把你的解说录音放这里
解说音频\                 生成的音频
index-tts\                项目二引擎 IndexTTS-2.5（tts_server.py 为自研封装）
GPT-SoVITS\               项目一引擎 GPT-SoVITS（api_server.py 为自研封装，训练+推理）
```

模型缓存全部固定在 `工作台\model_cache\`，不占 C 盘。

## 常见问题

- **点朗读后要等多久**：第一次点朗读会自动启动语音引擎并加载模型（IndexTTS-2.5 约 3~5 分钟，
  页面会显示"引擎加载中"进度）；之后再点就是秒级响应。
- **引擎加载失败 / 一直启动中**：双击 `工作台\修复wetext.bat`。wetext 包在 Windows +
  中文路径下会让 IndexTTS 引擎加载必败，脚本会装齐依赖、补全包数据并打补丁，可重复执行。
- **生成解说词报错提示配置 DeepSeek**：把 Key 填进 `工作台\config.yaml` 保存后重试即可，无需重启。
- **训练报素材为空**：录音还没放进 `训练素材\`，或格式不在 mp3/wav/flac/m4a/ogg 里。
- **显存**：RTX 4080 16GB 够用；训练时不要同时合成（工作台按需切换引擎）。
- **换音色/情绪**：项目一换录音重新训练（或在页面「训练产物」里切换历史声音）；
  项目二在 `工作台\config.yaml` 的 `tts.index_tts.presets` 里加减情绪预设。
