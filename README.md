# 激情解说 · 两个独立项目

给一段故事，按约束文档生成激情洋溢的解说词，再用语音引擎朗读出来。
本仓库是**两个互相独立的项目**，各自有自己的工作台页面、语音引擎、启动/关闭脚本和测试目录：

| | 项目文件夹 | 声音 | 引擎 | 工作台地址 |
|---|---|---|---|---|
| **项目一 · 专属声音** | `项目一-专属声音\` | 你自己训练出来的声音（未训练时用默认参考音色零样本克隆） | GPT-SoVITS（训练+推理） | http://127.0.0.1:9610 |
| **项目二 · 情感解说** | `项目二-情感解说\` | IndexTTS-2.5 情感声音模型（激情洋溢/兴奋/愤怒/惊喜…） | IndexTTS-2.5（B站开源） | http://127.0.0.1:9620 |

```
故事（或素材文字）
   │  DeepSeek 按「约束文档」改写（无 Key 回退本地 Ollama）
   ▼
激情解说词（每段带情感标注：兴奋 0.9 / 惊喜 1.0 …）
   │  逐段交给语音引擎朗读，自动拼接
   ▼
解说音频（wav，存各自项目的 解说音频\）
```

## 使用

- **启动**：进入对应项目文件夹，双击 `启动.bat`，浏览器自动打开工作台页面。
- **停止**：双击同目录的 `关闭.bat`（或直接关掉启动窗口）。
- **解说词 Key**：分别填在各自项目 `config.yaml` 的 `deepseek.api_key`（保存即生效，无需重启）。
- **测试成果**：每个项目的截图、音频产物和测试报告都在各自的 `测试\` 文件夹。
- 两个项目可同时运行（端口不同）；16GB 显存建议不要同时合成。

各项目的详细用法、接口文档见对应文件夹里的 `README.md` 和 `接口文档.md`。
